# UE5-Vegetation-PCG-System

> UE5 植被 PCG 系统 | TA 作品集项目

## 项目简介
基于 UE5 PCG 框架的植被程序化生成系统，目标实现大规模森林散布、工具链参数控制与实时性能优化。

## 技术栈
- UE 5.7.4 (PCG + HISM + EUW + WPO)
- Python 3.12 (工具链)
- 目标：2 km² 场景，10000+ 树木实时响应

## 项目结构（规划）
- `tools/` — 工具脚本
- `plugin/` — PCG 资产与插件
- `docs/` — 架构与调研文档
- `releases/` — 版本发布
